Conecta tu repositorio de GitHub

Este panel edita el contenido del sitio (pilotos, calendario, resultados, equipos, noticias) y sube los cambios directamente a tu repositorio en GitHub. Todo lo que escribas aquí se guarda solo en tu navegador, nunca se envía a ningún otro servidor.

¿Cómo consigo el token?
  1. Entra a github.com/settings/tokens
  2. Crea un Fine-grained token, dale acceso solo a tu repositorio del sitio
  3. En permisos, activa Contents: Read and write
  4. Copia el token generado y pégalo abajo (empieza con github_pat_)
Debe apuntar a la carpeta que contiene drivers.json, schedule.json, etc.
Se guarda únicamente en este navegador (localStorage). No se comparte con nadie más.
